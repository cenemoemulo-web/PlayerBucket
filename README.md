## 📖 About

**PlayerBucket** brings a chaotic new mechanic to Minecraft: capture other players inside buckets!

Whether you're messing around with friends or adding a unique twist to your server, PlayerBucket turns an ordinary bucket into an unforgettable experience.

## ✨ Features

| Feature | Description |
|:--|:--|
| 🪣 **Player Capture** | Capture other players inside buckets. |
| 🧮 **Math Challenges** | Captured players must solve a math problem to escape. |
| ⚔️ **PvP Protection** | Prevent PvP while a player is trapped inside a bucket. |
| 🔥 **Lava Safety** | Players are released and teleported to safety if their bucket enters lava. |
| 🛡️ **Despawn Protection** | Players are released if their bucket is about to despawn. |
| 🌍 **Chunk Protection** | Players are released if the chunk containing their bucket unloads. |

## 🎮 Gameplay

The basic idea is simple:

1. Capture another player using PlayerBucket.
2. Keep them trapped inside the bucket.
3. Make them solve the math challenge to escape.
4. Avoid dangerous situations — the plugin includes safety mechanisms for lava, despawning, and chunk unloading.
